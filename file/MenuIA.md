- **최종 수정일**: 2026-07-24
- **버전**: v1.0.0

## 🗺️ 1. 글로벌 네비게이션 바 (GNB) 요약
- **유형**: 탑 네비게이션 (데스크톱 1200px 이상 기준) / 드롭다운 메가 메뉴
- **모바일**: 768px 미만 환경에서 우측 상단 햄버거 메뉴(토글) 형태로 전환 (터치 최소 영역 44×44pt 보장)
- **공통 탑 영역**: 민간 간편인증 통합 로그인, 회원가입, 사이트맵, 글자 크기 조절 기능
