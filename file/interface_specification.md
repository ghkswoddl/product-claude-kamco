# 화면별 필수 입력값 및 검색 조건을 기준 연동 인터페이스 명세서

본 명세서는 각 화면에서 사용자가 직접 입력하는 필수 입력값(Form Data) 및 검색/조회 조건(Search Filters)을 기준으로, 해당 데이터를 처리·검증·연동하기 위해 필요한 내·외부 연동 인터페이스(API/EAI/FEP) 목록을 정의한 문서입니다.

---

## 1. 기업지원 프로그램 자가진단 및 신청

### 1) 필터 / 검색 항목별 연동 인터페이스

| 구분 | 화면 내 검색/조회 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **조회** | 기업 기본 정보<br>*(기업명, 대표자명, 주소)* | 사업자 등록 실명 인증 API | 외부 (NICE / KCB 등) | 입력한 사업자번호의 실제 존속 여부 및 법인 실명 검증 |
| **조회** | 공공 마이데이터 서류<br>*(재무제표, 등기부등본 등)* | 공공 마이데이터 API | 외부 (행안부 / 국세청 / 대법원) | 사업자번호 기반 전자증명서(국세/지방세/재무제표) 자동 조회 및 가져오기 |
| **검색** | 주소 검색 | 도로명주소 검색 API | 외부 (행정안전부 주소 API) | 기본 주소 및 우편번호 조회/자동 입력 |

### 2) 필수 입력 항목별 연동 인터페이스

| 구분 | 화면 내 필수 입력 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **입력** | 자가진단 항목<br>*(매출액, 부채비율, 구조조정 단계)* | 자가진단 매칭 엔진 API | 내부 (캠코 추천 모듈) | 입력된 재무/상황 데이터 기반 지원 가능 프로그램 추천 목록 반환 |
| **입력** | 신청인 본인 확인<br>*(담당자 이름, 휴대폰번호)* | 휴대폰 본인인증 API | 외부 (NICE / PASS 등) | 작성 담당자의 본인 명의 인증 처리 (PASS, SMS 인증) |
| **입력** | 전자 서명<br>*(신청서 및 동의서 서명)* | 법인/개인 전자서명 API | 외부/내부 (모피어스 / 인증서) | 신청 동의서에 대한 PKI 기반 전자서명 값 생성 및 검증 |
| **제출** | 신청서 전체 데이터<br>*(신청서 + 첨부파일)* | 기업지원 신청원장 등록 API | 내부 (캠코 BO 통합 DB) | 제출된 입력값 및 파일 객체를 BO 접수 원장 테이블에 1:1 저장 |
| **알림** | 접수 완료 안내 | 알림톡/SMS 발송 API | 외부 (카카오 알림톡/문자 FEP) | 접수 완료 시 접수번호(ON-2026...) 및 담당 부서 안내 메시지 발송 |

## 2. 마이페이지 - 신청 및 진행 현황

### 1) 필터 / 검색 항목별 연동 인터페이스

| 구분 | 화면 내 검색/조회 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **조회** | 신청 내역 조회<br>*(접수번호, 신청사업명, 접수일자)* | 마이페이지 신청목록 조회 API | 내부 (캠코 BO 원장) | 로그인한 기업(사업자번호 기준)의 전체 신청 내역 불러오기 |
| **조회** | 진행 상태 및 타임라인<br>*(STATUS 01 ~ 05)* | BO 심사 상태값 수신 API / Websocket | 내부 (캠코 BO 심사 DB) | BO 담당자가 변경한 심사 단계 코드를 실시간 조회하여 프로그레스 바 바인딩 |
| **조회** | 서류 보완 요청 사유 | 보완 요청 상세내역 조회 API | 내부 (캠코 BO 원장) | STATUS 02 상태 시 BO 담당자가 기재한 핀포인트 보완 사유 텍스트 수집 |

### 2) 필수 입력 항목별 연동 인터페이스

| 구분 | 화면 내 필수 입력 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **입력** | 보완 서류 재첨부<br>*(지정된 보완 서류 파일)* | 보완 서류 핀포인트 업데이트 API | 내부 (캠코 BO 문서 서버) | 기존 전체 신청서 수정 없이, 보완 지정된 서류 파일만 덮어쓰기(Update) |
| **입력** | 1:1 담당자 문의<br>*(제목, 문의 내용)* | 담당자 1:1 문의 등록 API | 내부 (BO 담당자 메신저/Q&A) | 해당 사건 담당 직원 BO 화면으로 문의 전달 및 답변 수신 연동 |
| **입력** | 실사 일정 변경 요청<br>*(희망 일시, 사유)* | 실사 일정 조율 요청 API | 내부 (캠코 BO 실사관리) | 기업 측 희망 일정을 BO 실사 담당자 스케줄러로 전달 |
| **입력** | 부동산 전자계약 서명<br>*(STATUS 05 승인 시)* | 부동산거래 전자계약 SSO/API | 외부 (국토교통부 전자계약) | 계약 승인건 데이터를 국토부 전자계약 시스템으로 이전하여 계약 체결 연동 |

## 3. 투자자 라운지

### 1) 필터 / 검색 항목별 연동 인터페이스

| 구분 | 화면 내 검색/조회 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **검색** | 업종 구분 | 업종 분류 코드 조회 API | 내부 (공통 코드 DB) | 한국표준산업분류(KSIC) 기반 업종 드롭다운 리스트 호출 |
| **검색** | 희망 투자금액 / 지역 / 유형 | 딜(Deal) 탐색 다중 필터 API | 내부 (캠코 BO 투자원장) | 투자자가 선택한 조건(예: 제조업, 50억~100억, S&LB)에 맞는 기업 카드 목록 조회 |
| **검색** | 기업명/키워드 검색 | 투자 대상 기업 검색 API | 내부 (검색 엔진 / DB) | 검색어에 해당하는 투자 유치 기업 실시간 검색 |

### 2) 필수 입력 항목별 연동 인터페이스

| 구분 | 화면 내 필수 입력 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **입력** | 투자 의향서(LOI) 입력<br>*(제시 투자금액, 투자 방식, 조건)* | LOI 서식 데이터 저장 API | 내부 (캠코 BO 투자관리 DB) | 작성한 LOI 전자 폼 데이터를 BO 담당자 원장에 등록 |
| **입력** | 투자 기관 서명<br>*(대표자/담당자 인감)* | 전자서명 연동 API | 외부/내부 (모피어스 등) | 제출하는 LOI 서식에 대한 전자서명 값 검증 및 PKI 암호화 |

## 4. 국유증권 가상데이터룸(VDR)

### 1) 필터 / 검색 항목별 연동 인터페이스

| 구분 | 화면 내 검색/조회 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **조회** | VDR 대상 주식 목록 | 국유증권 매각 물목 조회 API | 내부 (캠코 국유증권 DB) | 물납주식 기업명, 매각 대상 주식 수, 가치평가 상태 조회 |
| **조회** | 문서 폴더 구조 (Tree) | VDR 디렉토리/파일 목록 API | 외부/내부 (VDR 솔루션 API) | 접속자의 권한 등급에 따라 열람 가능한 폴더 및 파일 트리 구조 반환 |

### 2) 필수 입력 항목별 연동 인터페이스

| 구분 | 화면 내 필수 입력 항목 | 연동 인터페이스명 | 연동 대상 (내/외부) | 데이터 흐름 및 역할 |
| :--- | :--- | :--- | :--- | :--- |
| **입력** | 비밀유지약정(NDA) 동의<br>*(서명, 접속 목적)* | 전자 NDA 체결 및 권한 승인 API | 내부/보안 솔루션 | NDA 전자서명 저장 후 해당 국유증권 VDR 접속 권한(Token) 즉시 발급 |
| **보안** | 동적 워터마크 정보<br>*(자동 수집 항목)* | 동적 워터마크 생성 모듈 | 외부 (보안 DRM 솔루션) | 접속자 계정 ID, IP, 접속 일시를 뷰어 상단에 투명 오버레이로 자동 실시간 연동 |
| **보안** | 열람 이력 (자동 트래킹) | VDR 감사 로그(Audit Log) API | 내부/외부 (BO 감사 서버) | 열람한 파일 ID, 열람 시간, 체류 시간, 페이지 이동 이력을 실시간 전송 저장 |

## 5. 개발자 전달용 데이터 흐름 요약 Matrix

```text
[사용자 입력/검색] 
      │
      ├─► (1) 공공/인증 연동 ──► [국세청/정부24/NICE] (서류 자동수집 & 본인인증)
      ├─► (2) 보안/DRM 연동   ──► [VDR 보안/전자서명]  (워터마크, 캡처방지, NDA)
      ├─► (3) 내부 DB 연동    ──► [캠코 BO 원장 DB]   (신청서 저장, 상태 실시간 수신)
      └─► (4) 외부 시스템 연동 ──► [국토부/카카오 FEP] (전자계약, 알림톡 발송)
```
